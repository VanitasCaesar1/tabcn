# tabcn

The foundation package for [tabcn](../../README.md): animated, copy-and-own tab bars for React Native and Expo.

> Status: pre-release. The API is being designed in [`docs/designs/`](../../docs/designs/).

This package will hold the parts every design shares: connecting to the navigator, tab state, safe-area spacing, the animated active-tab highlight, press feedback, badges, haptics, reduced-motion support and accessibility. The designs themselves live in [`registry/`](../../registry/) and are copied into your app.
