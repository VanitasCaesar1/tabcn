# tabcn example app

Expo SDK 58 + Expo Router app that shows every tabcn design. Start it from the repo root with `bun run example` (or `bun run ios` / `bun run android`).

- `src/catalog.ts`: the list of designs and their status.
- `src/app/index.tsx`: the gallery.
- `src/app/designs/[id].tsx`: one screen per design (placeholders until each is built).
