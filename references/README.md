# References

The images that inspired the 20 designs come from a public post on X ("tab bar pillars", https://x.com/jaimintf/status/2123071132224077889). They show tab bars from other people's apps, so they stay out of git: everything in this folder except this README is git-ignored.

To restore them locally, download the post's 20 images into this folder as `01-*.jpg` … `20-*.jpg`, in the order they appear in the post. Image `NN` matches catalog entry `ref: NN` in `apps/example/src/catalog.ts`.

The images are rotated 90°: each one shows a horizontal tab bar standing on its end.

Use these images for layout and proportions only. Don't copy icons, illustrations, mascots or brand names from them.
